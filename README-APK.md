# MiladGeo Android

این پروژه نسخه اندرویدی MiladGeo را بر پایه `index109.html` می‌سازد.

## ساخت APK با GitHub Actions

1. کل پوشه پروژه را داخل یک repository در GitHub قرار بده.
2. به تب **Actions** برو.
3. workflow با نام **Build MiladGeo APK** را انتخاب کن.
4. روی **Run workflow** بزن.
5. بعد از پایان Build، در بخش **Artifacts** فایل `MiladGeo-debug-apk` را دانلود کن.
6. فایل `app-debug.apk` را روی گوشی نصب کن.

این نسخه HTML را داخل خود اپ قرار می‌دهد و برای اجرای رابط اصلی به اینترنت نیاز ندارد.
